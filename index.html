GITHUB API

Подключить репозиторий

Для запуска из сайта нужен fine-grained токен GitHub только для этого репозитория: Actions — read/write, Contents — read. Токен хранится лишь в памяти открытой вкладки и отправляется только на api.github.com.

Создать токен доступа ↗

В GitHub выберите «Only select repositories» → law-monitor-rf. В Repository permissions задайте Actions: Read and write и Contents: Read-only. Скопируйте созданный токен в поле ниже.

Токен не сохраняется в localStorage, cookies или URL. После подключения запускайте проверки кнопкой на сайте.
